# PakScape privacy policy

Effective October 7, 2026.

PakScape is a desktop archive editor. It does not require an account. PakScape has no developer-operated data collection backend, usage analytics, advertisements, or tracking. The main archive editing and built-in preview features process files locally. Optional browser demo playback makes the external requests described below.

Archives and files you open, edit, preview, save, or extract are processed locally on your Mac. Preferences are stored locally. Preview and transfer operations may create temporary files on your Mac.

Optional demo playback opens a separate browser or a Quake engine you select. Browser playback opens https://q1tools.github.io/demo/play/, hosted by GitHub Pages. The launch URL sends the demo filename/title, map names, duration when available, package filenames, and temporary tokenized loopback source URLs to that website. The website host also receives normal web-request information, such as your IP address and browser headers, and may retain request logs under its own privacy practices. Filenames and titles may contain information you have put in them.

The demo and archive package bytes are served to the browser through a temporary loopback-only connection on your Mac; PakScape does not upload those file bytes to the website. Local playback sessions expire after 15 minutes. You can use the main app and built-in previews without browser demo playback. External links open in your browser.

Apple handles Mac App Store downloads, purchases, diagnostics, and related account information under Apple's privacy policy. Data you choose to provide in a support request or public GitHub issue is handled by GitHub and is visible according to the issue's access settings. Do not include private archives or personal information in public issues.

For privacy questions or support, contact the maintainer through [PakScape's GitHub issue tracker](https://github.com/timbergeron/PakScape/issues). Changes to this policy will be published here.
